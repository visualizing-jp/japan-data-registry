# データソース

「日本の土地と建物はどう名義が動いてきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-11。軸は e-Stat 年報 Excel の実測値で確認済み。

## 1. 結論

土地と建物の名義の動きと、会社の生まれ消えを、**時代・種類・商業**の3ビューで見せる。
一次ソースは法務省「登記統計」（政府統計コード `00250002`）年報の**累年比較表**。

e-Stat データベース表は単年表が中心で、長期比較には向かない。第1版は年報の累年表のみ。API / SSDS は使わない。地域（地方法務局）は第1版の対象外。`housing` の姉妹。

| ビュー | 一次ソース | 表 | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 登記統計年報 | `24-00-1` + `24-00-4` / `24-00-5` | 指標×年 | 総数・不動産・土地・建物、売買/相続/贈与/抵当 |
| 種類 | 登記統計年報 | `24-00-4` | 種類×年 | 土地の件数・構成比 |
| 商業 | 登記統計年報 | `24-00-16` / `24-00-20` | 指標×年 | 株式会社・合同会社の設立と解散 |

出典表記: 法務省「登記統計」（e-Stat）。

## 2. 採用データセット（メタ・実測）

### `24-00-1.xlsx` — 登記事件の件数及び個数（2010–2024）

- 出典: 2024年年報 総括・不動産（lid=`000001460052`、statInfId=`000040280811`）
- 件数列: 総数 col6 / 不動産 col8 / 土地 col10 / 建物 col12
- 実測（2024年）: 総数 **12,786,317** / 不動産 **10,905,928** / 土地 **7,520,415** / 建物 **3,385,513**
- 2010年総数: 13,834,560

### `24-00-4.xlsx` / `24-00-5.xlsx` — 種類別 土地・建物（2015–2024）

- statInfId: 土地 `000040280814` / 建物 `000040280815`
- 種類が行、年が列（令和6→平成27 = col 6–15）。件数行を読む
- 実測（土地 2024年）:
  - 売買 **1,319,034**
  - 相続による 986,295 + 一般承継（相続を除く）41,347 = **1,027,642**（接続後）
  - 贈与 180,651 / 抵当権設定 627,486 / 根抵当 130,293
  - 所有権の保存 27,247 / 表示 1,651,357
- 実測（建物 2024年）: 売買 388,573 / 相続接続 171,086+1,119 / 抵当 359,037

### `24-00-16.xlsx` / `24-00-20.xlsx` — 株式会社・合同会社（2015–2024）

- 出典: 2024年年報 商業・法人（lid=`000001460053`）
- statInfId: 株式会社 `000040280890` / 合同会社 `000040280894`
- 本店の「設立」「解散」
- 実測（2024年）: 株式会社設立 **98,671** / 解散 20,795。合同会社設立 **41,774** / 解散 5,279
- 合同会社設立は2015年 22,223 からほぼ倍増

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| `24-00-10` 地方法務局 | 管内と総数を除く50庁。地図の物語ではない。第2版 |
| 個数 | 件数のほうが事件の単位として読みやすい |
| 表示の内訳・筆界特定 | 名義の核から外れる |
| 合名・合資・特例有限 | 合同会社の急増が核 |
| 月次データベース表 | 長期比較には年報累年で足りる |

## 4. 接続・定義ルール

- **件数** = 登記事件の件数。1件に複数の土地・建物が乗る
- **売買 / 贈与 / 抵当（時代）** = 土地件数 + 建物件数
- **相続** = 2015–2023 は「相続その他一般承継による所有権の移転」。2024年は「相続による」+「一般承継（相続を除く）」を足す。旧行（土地 344,851）は1–3月分なので使わない
- **商業** = 本店。支店は含めない。解散は「解散」であり合併による解散は別行
- 表示年は西暦。欠測は `null`（名義4系列は2014年以前）

## 5. 配信ファイル

`scripts/build_data.py` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | metric × year | counts | metrics |
| `type.json` | code × year | counts / share | codes |
| `company.json` | metric × year | counts | metrics |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。
種類の構成比は土地の総数に対する割合。種類は互いに排他ではない。

## 6. 注記（UIに短く出す）

- 2024年に相続の定義が分かれた
- 売買は土地のほうが建物より多い
- 合同会社の設立は10年でほぼ倍
- 件数と個数は違う

## 7. 更新手順

API キーは不要。

1. `npm run fetch` で年報 Excel を `data/raw/estat/` に置く
2. [e-Stat 登記統計](https://www.e-stat.go.jp/stat-search/files?toukei=00250002) の lid / statInfId は `scripts/fetch-xlsx.sh` が持っている。新年報では差し替える
3. `npm run data && npm run verify`
4. 総数・相続の接続・株式会社設立が年報と一致することを確認する

`ESTAT_APP_ID` は第2版で API を使うときまで不要。配信用 JSON は追跡する。
